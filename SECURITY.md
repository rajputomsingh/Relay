# Security Policy

## Supported versions

Only the latest release of Relay is supported with security updates.

| Version | Supported |
|---------|-----------|
| v1.1.x  | Yes       |
| < v1.1  | No        |

## Reporting a vulnerability

Do not open a public issue for security vulnerabilities.

Report via GitHub's private vulnerability reporting:

1. Go to Security Advisories at https://github.com/rajputomsingh/Relay/security/advisories
2. Click Report a vulnerability
3. Describe the issue with reproduction steps and affected version

You should receive a response within 72 hours.

## What counts as a security issue

- Authentication or authorization bypass
- Injection (SQL, command, template)
- SSRF in webhook delivery
- HMAC signature forgery
- Denial of service via unbounded resource usage
- Exposure of secrets

## Disclosure

Coordinated disclosure: 30 days for non-critical, 7 days for critical.
