## How to contribute

1. Read the linked issue and check the existing implementation.
2. Comment on the issue describing your intended approach.
3. Wait for maintainer confirmation before starting substantial work.
4. Follow CONTRIBUTING.md and the existing code conventions.
5. Open a focused pull request with tests and documentation where applicable.
6. Reference the issue using Closes #<number> in your pull request.

## Contribution expectations

- Keep pull requests focused and reviewable.
- Add tests for behavior changes.
- Avoid unrelated refactoring.
- Discuss significant API or architecture changes before implementation.
- Be responsive to review feedback.

If you are unsure where to start, comment here with your experience and the area you want to contribute to.
